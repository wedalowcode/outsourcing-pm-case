# 8.1 用户管理：构建公共组件并实现列表查询

## 一、先明确组件的职责边界

目前，部门管理已经具备搜索、表格和分页功能。实现用户管理时，我们不应该直接导入部门管理内部的组件，也不应该把这些组件复制一份到用户管理目录。

例如，如果用户管理这样导入组件：

```tsx
import { SearchBar } from "../dept/_components/search-bar";
import { Pagination } from "../dept/_components/pagination";
```

虽然可以正常运行，但这意味着用户管理依赖部门管理。随着项目功能增加，客户管理、项目管理、任务管理都会需要搜索和分页，如果每个模块都依赖部门管理，业务模块之间就会形成不必要的耦合。

因此，本节先调整公共组件的组织方式，再完成用户管理列表查询。

### 1.1 规划组件目录

项目现有 `components/` 目录中已经有 `layout/` 和 `ui/`。我们在此基础上增加 `common/`，专门存放与具体业务模块无关、可在多个页面复用的交互组件。

调整后的目录结构如下：

```text
components/
├── layout/                   # 应用整体布局
├── ui/                       # 基础 UI 组件
│   ├── button.tsx
│   ├── input.tsx
│   ├── select.tsx
│   └── table.tsx
└── common/                   # 项目公共交互组件
    ├── search-bar.tsx
    └── pagination.tsx

app/
└── (dashboard)/
    ├── dept/                 # 部门管理业务
    │   ├── _components/      # 部门专属组件
    │   │   └── workspace.tsx
    │   └── page.tsx
    └── users/                # 用户管理业务
        ├── user-workspace.tsx
        └── page.tsx

server/
├── dept/                     # 部门业务服务
└── user/                     # 用户业务服务
```

这里有三个层次。

- `components/ui/` 负责基础控件，例如按钮、输入框、下拉选择和表格。
- `components/common/` 负责项目中反复出现的通用交互模式，例如搜索栏、分页器。
- `app/(dashboard)/` 中的业务组件负责将基础控件和公共组件组合起来，完成具体业务。

例如，搜索栏本身不关心搜索的是部门、用户还是项目。业务模块只需要传入默认关键字、占位提示和搜索回调即可。

## 二、将搜索栏提升为公共组件

先把部门管理现有的搜索组件迁移到：

`components/common/search-bar.tsx`

与原组件相比，这里使用项目已经引入的 shadcn/ui `Input` 和 `Button`，并增加 `placeholder` 属性，使它能够适应不同业务模块。

```tsx
"use client";

import { useState } from "react";
import { Input } from "@/components/ui/input";
import { Button } from "@/components/ui/button";

type SearchBarProps = {
  defaultValue: string;
  placeholder?: string;
  onSearch: (keyword: string) => void;
};

export function SearchBar({
  defaultValue,
  placeholder = "请输入关键字",
  onSearch,
}: SearchBarProps) {
  const [draft, setDraft] = useState(defaultValue);

  function handleSubmit(
    event: React.FormEvent<HTMLFormElement>
  ) {
    event.preventDefault();
    onSearch(draft.trim());
  }

  return (
    <form
      onSubmit={handleSubmit}
      className="flex w-full max-w-md items-center gap-2"
    >
      <Input
        value={draft}
        onChange={(event) => setDraft(event.target.value)}
        placeholder={placeholder}
      />

      <Button type="submit" variant="outline">
        查询
      </Button>
    </form>
  );
}
```

### 2.1 为什么搜索栏不直接操作 URL

公共组件只负责两件事：维护输入框中的草稿值，以及在用户提交时通知调用方。

它不应该知道 `/dept` 或 `/users` 这样的业务路由，也不应该自行拼接查询参数。

这样，部门管理可以传入部门名称或编码的提示语，用户管理可以传入用户名、姓名或邮箱的提示语，而搜索后的行为仍然由各自的业务页面决定。

### 2.2 调整部门管理的引用

原来的文件位于：

`app/(dashboard)/dept/_components/search-bar.tsx`

迁移后，部门管理应改为导入公共组件：

```tsx
import { SearchBar } from "@/components/common/search-bar";
```

原有使用方式基本不变，只需要增加更符合部门业务的占位提示：

```tsx
<SearchBar
  key={keyword}
  defaultValue={keyword}
  placeholder="搜索部门名称 / 编码"
  onSearch={(kw) => go({ keyword: kw })}
/>
```

确认没有其他引用后，可以删除旧的 `dept/_components/search-bar.tsx`，避免项目中同时保留两份实现。

## 三、将分页器提升为公共组件

接下来迁移部门管理的分页组件。

新文件：

`components/common/pagination.tsx`

这次除了调整目录，还将内部的原生按钮替换成项目已有的 shadcn/ui `Button`。

```tsx
"use client";

import { Button } from "@/components/ui/button";

type PaginationProps = {
  page: number;
  total: number;
  pageSize: number;
  onChange: (page: number) => void;
};

export function Pagination({
  page,
  total,
  pageSize,
  onChange,
}: PaginationProps) {
  const pageCount = Math.max(
    1,
    Math.ceil(total / pageSize)
  );

  return (
    <div className="mt-3 flex items-center justify-between gap-3 text-sm text-muted-foreground">
      <span>
        共 {total} 条 · 第 {page}/{pageCount} 页
      </span>

      <div className="flex items-center gap-2">
        <Button
          type="button"
          variant="outline"
          size="sm"
          disabled={page <= 1}
          onClick={() => onChange(page - 1)}
        >
          上一页
        </Button>

        <Button
          type="button"
          variant="outline"
          size="sm"
          disabled={page >= pageCount}
          onClick={() => onChange(page + 1)}
        >
          下一页
        </Button>
      </div>
    </div>
  );
}
```

分页组件只关心当前页、总记录数、每页条数和页码变化回调，不负责查询数据库，也不负责生成业务 URL。

### 3.1 调整部门管理的引用

将部门管理中的导入修改为：

```tsx
import { Pagination } from "@/components/common/pagination";
```

调用方式保持不变：

```tsx
<Pagination
  page={pageData.page}
  total={pageData.total}
  pageSize={pageData.pageSize}
  onChange={(page) => go({ page })}
/>
```

迁移完成后，可以删除原来的：

`app/(dashboard)/dept/_components/pagination.tsx`

至此，搜索栏和分页器已经从部门管理的局部实现升级为项目公共组件。

## 四、定义用户列表查询 Service

公共组件调整完成后，再开始用户管理的业务开发。

创建文件：

`server/user/service.ts`

```ts
import "server-only";
import { db } from "@/lib/db";

export type UserListOptions = {
  keyword?: string;
  status?: "ACTIVE" | "DISABLED";
  page?: number;
  pageSize?: number;
};

export async function listUserPage(
  options: UserListOptions = {}
) {
  const keyword = options.keyword?.trim() ?? "";
  const status = options.status;

  const pageSize = Math.min(
    Math.max(Math.floor(options.pageSize ?? 10), 1),
    100
  );

  const where = {
    ...(keyword
      ? {
          OR: [
            {
              username: {
                contains: keyword,
                mode: "insensitive" as const,
              },
            },
            {
              name: {
                contains: keyword,
                mode: "insensitive" as const,
              },
            },
            {
              email: {
                contains: keyword,
                mode: "insensitive" as const,
              },
            },
          ],
        }
      : {}),
    ...(status ? { status } : {}),
  };

  const total = await db.user.count({ where });

  const totalPages = Math.max(
    1,
    Math.ceil(total / pageSize)
  );

  const page = Math.min(
    Math.max(Math.floor(options.page ?? 1), 1),
    totalPages
  );

  const items = await db.user.findMany({
    where,
    select: {
      id: true,
      username: true,
      name: true,
      email: true,
      phone: true,
      status: true,
      createdAt: true,
    },
    orderBy: [
      { createdAt: "desc" },
      { id: "desc" },
    ],
    skip: (page - 1) * pageSize,
    take: pageSize,
  });

  return {
    items,
    total,
    page,
    pageSize,
    totalPages,
  };
}
```

### 4.1 查询条件

用户列表提供两个查询条件：

| 条件 | 查询规则 |
|---|---|
| 关键字 | 匹配用户名、姓名或邮箱 |
| 用户状态 | 全部、正常、已禁用 |

关键字中的三个字段采用 OR 关系，状态条件与关键字条件组合生效。

### 4.2 分页与返回字段

Service 先统计符合条件的记录总数，再计算总页数并限制当前页码，最后只读取当前页数据。

`select` 明确限定返回字段，避免将 `passwordHash` 等认证敏感数据传递给页面。排序则采用创建时间倒序，并以 ID 作为次级排序条件。

## 五、实现用户管理页面

创建文件：

`app/(dashboard)/users/page.tsx`

页面负责读取 URL 查询参数，调用 Service 查询数据，再把数据交给客户端工作区组件。

```tsx
import { listUserPage } from "@/server/user/service";
import { UserWorkspace } from "./user-workspace";

export default async function UsersPage({
  searchParams,
}: {
  searchParams: Promise<{
    keyword?: string;
    status?: string;
    page?: string;
  }>;
}) {
  const params = await searchParams;

  const keyword = params.keyword?.trim() ?? "";

  const status =
    params.status === "ACTIVE" ||
    params.status === "DISABLED"
      ? params.status
      : undefined;

  const parsedPage = Number(params.page ?? "1");

  const page =
    Number.isInteger(parsedPage) && parsedPage > 0
      ? parsedPage
      : 1;

  const pageData = await listUserPage({
    keyword,
    status,
    page,
    pageSize: 10,
  });

  return (
    <UserWorkspace
      pageData={pageData}
      keyword={keyword}
      status={status ?? ""}
    />
  );
}
```

这里采用与部门管理一致的服务端查询方式。URL 中的查询参数是页面状态的来源，例如：

`/users?keyword=admin&status=ACTIVE&page=2`

用户刷新页面或复制地址后，服务端就可以根据这些参数重新加载对应的数据。

本节不额外创建用户列表查询 Action，因为客户端通过更新 URL 触发服务端页面重新查询即可。后续新增、编辑、禁用用户等写操作，再通过 Server Actions 处理。

## 六、实现 UserWorkspace

创建文件：

`app/(dashboard)/users/user-workspace.tsx`

这个组件组合公共搜索栏、shadcn/ui 下拉选择、shadcn/ui 表格和公共分页器，完成用户列表的展示与交互。

首先引入组件：

```tsx
"use client";

import { useRouter } from "next/navigation";
import { useTransition } from "react";

import { SearchBar } from "@/components/common/search-bar";
import { Pagination } from "@/components/common/pagination";
import { Button } from "@/components/ui/button";

import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select";

import {
  Table,
  TableBody,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
} from "@/components/ui/table";
```

如果项目中尚未生成 `components/ui/table.tsx`，先执行：

```bash
pnpm dlx shadcn@latest add table
```

接着定义页面数据类型：

```tsx
type UserStatus = "ACTIVE" | "DISABLED";

type UserItem = {
  id: string;
  username: string;
  name: string;
  email: string | null;
  phone: string | null;
  status: UserStatus;
  createdAt: Date;
};

type UserPageData = {
  items: UserItem[];
  total: number;
  page: number;
  pageSize: number;
  totalPages: number;
};

type UserWorkspaceProps = {
  pageData: UserPageData;
  keyword: string;
  status: "" | UserStatus;
};
```

完整组件如下：

```tsx
export function UserWorkspace({
  pageData,
  keyword,
  status,
}: UserWorkspaceProps) {
  const router = useRouter();
  const [isPending, startTransition] = useTransition();

  function go(next: {
    keyword?: string;
    status?: "" | UserStatus;
    page?: number;
  }) {
    const nextKeyword = next.keyword ?? keyword;
    const nextStatus =
      next.status === undefined ? status : next.status;
    const nextPage = next.page ?? 1;

    const params = new URLSearchParams();

    if (nextKeyword) {
      params.set("keyword", nextKeyword);
    }

    if (nextStatus) {
      params.set("status", nextStatus);
    }

    if (nextPage > 1) {
      params.set("page", String(nextPage));
    }

    const query = params.toString();
    const url = query ? `/users?${query}` : "/users";

    startTransition(() => {
      router.push(url);
    });
  }

  function handleStatusChange(value: string | null) {
    // SelectItem 的 value 全部使用中文，按钮上始终显示中文标签；
    // 这里把中文值映射回内部状态供 URL 和 Service 使用。
    if (value === "全部状态") {
      go({ status: "", page: 1 });
      return;
    }
    if (value === "正常") {
      go({ status: "ACTIVE", page: 1 });
      return;
    }
    if (value === "已禁用") {
      go({ status: "DISABLED", page: 1 });
    }
  }

  function handleReset() {
    startTransition(() => {
      router.push("/users");
    });
  }

  return (
    <div className="space-y-4">
      <div>
        <h1 className="text-xl font-semibold">用户管理</h1>
        <p className="mt-1 text-sm text-muted-foreground">
          查询和查看系统用户信息。
        </p>
      </div>

      <div className="flex flex-wrap items-center gap-3">
        <SearchBar
          key={keyword}
          defaultValue={keyword}
          placeholder="搜索用户名 / 姓名 / 邮箱"
          onSearch={(value) =>
            go({ keyword: value, page: 1 })
          }
        />

        {/* value 使用中文，SelectValue 才能把匹配的 SelectItem.children 显示在按钮上；
            内部 ACTIVE / DISABLED 状态在 handleStatusChange 里做映射。 */}
        <Select
          value={status === "ACTIVE" ? "正常" : status === "DISABLED" ? "已禁用" : "全部状态"}
          onValueChange={handleStatusChange}
        >
          <SelectTrigger className="w-36">
            <SelectValue placeholder="全部状态" />
          </SelectTrigger>

          <SelectContent>
            <SelectItem value="全部状态">全部状态</SelectItem>
            <SelectItem value="正常">正常</SelectItem>
            <SelectItem value="已禁用">已禁用</SelectItem>
          </SelectContent>
        </Select>

        <Button
          type="button"
          variant="outline"
          disabled={isPending}
          onClick={handleReset}
        >
          重置
        </Button>
      </div>

      <div
        className={
          isPending
            ? "overflow-hidden rounded-md border opacity-60"
            : "overflow-hidden rounded-md border"
        }
      >
        <Table>
          <TableHeader>
            <TableRow>
              <TableHead>用户名</TableHead>
              <TableHead>姓名</TableHead>
              <TableHead>邮箱</TableHead>
              <TableHead>手机号</TableHead>
              <TableHead>状态</TableHead>
              <TableHead>创建时间</TableHead>
            </TableRow>
          </TableHeader>

          <TableBody>
            {pageData.items.length === 0 ? (
              <TableRow>
                <TableCell
                  colSpan={6}
                  className="h-24 text-center text-muted-foreground"
                >
                  没有符合条件的用户
                </TableCell>
              </TableRow>
            ) : (
              pageData.items.map((user) => (
                <TableRow key={user.id}>
                  <TableCell className="font-medium">
                    {user.username}
                  </TableCell>

                  <TableCell>{user.name}</TableCell>

                  <TableCell>
                    {user.email || "—"}
                  </TableCell>

                  <TableCell>
                    {user.phone || "—"}
                  </TableCell>

                  <TableCell>
                    <span
                      className={
                        user.status === "ACTIVE"
                          ? "text-green-600"
                          : "text-muted-foreground"
                      }
                    >
                      {user.status === "ACTIVE"
                        ? "正常"
                        : "已禁用"}
                    </span>
                  </TableCell>

                  <TableCell className="whitespace-nowrap">
                    {new Date(
                      user.createdAt
                    ).toLocaleString("zh-CN", {
                      year: "numeric",
                      month: "2-digit",
                      day: "2-digit",
                      hour: "2-digit",
                      minute: "2-digit",
                    })}
                  </TableCell>
                </TableRow>
              ))
            )}
          </TableBody>
        </Table>
      </div>

      <Pagination
        page={pageData.page}
        total={pageData.total}
        pageSize={pageData.pageSize}
        onChange={(page) => go({ page })}
      />
    </div>
  );
}
```

### 6.1 公共组件与业务组件如何协作

用户管理不需要知道搜索栏内部如何维护输入状态，也不需要重新实现分页按钮。

它只需要：

- 向 `SearchBar` 传递当前关键字和搜索回调。
- 向 `Pagination` 传递当前页码、总数、每页条数和翻页回调。
- 使用 shadcn/ui `Select` 实现用户状态筛选。
- 使用 shadcn/ui `Table` 展示用户数据。

业务组件负责组织这些能力，公共组件负责重复出现的交互模式，基础 UI 组件负责视觉和交互细节。

### 6.2 为什么 SelectItem 的 value 使用中文

shadcn/ui 的 `SelectValue` 会根据当前 value 匹配对应的 `SelectItem.children`，把它渲染在触发按钮上。如果 value 用的是英文 `"ALL"`、`"ACTIVE"`、`"DISABLED"`，而 children 是中文，按钮上就会直接显示英文内部值（截图中出现过 `ALL` 的问题）。

因此，所有 `SelectItem` 的 `value` 都使用中文：

```tsx
<SelectItem value="全部状态">全部状态</SelectItem>
<SelectItem value="正常">正常</SelectItem>
<SelectItem value="已禁用">已禁用</SelectItem>
```

这样 `SelectValue` 总能匹配到同一个 value 下的中文 children，按钮上始终显示中文标签。

内部状态仍然沿用 `ACTIVE` / `DISABLED`（数据库枚举和 URL 查询参数都用这个）。两者之间的转换集中在 `handleStatusChange` 中完成：

```tsx
if (value === "全部状态") {
  go({ status: "", page: 1 });
}
if (value === "正常") {
  go({ status: "ACTIVE", page: 1 });
}
if (value === "已禁用") {
  go({ status: "DISABLED", page: 1 });
}
```

同样地，传给 `Select` 的受控 value 也需要做反向映射：

```tsx
value={
  status === "ACTIVE" ? "正常"
  : status === "DISABLED" ? "已禁用"
  : "全部状态"
}
```

这套映射让 UI 层只出现中文，业务逻辑和数据库层继续使用枚举值，互不干扰。

### 6.3 为什么修改条件后回到第一页

关键字和状态变化后，符合条件的记录集合可能完全不同，因此将页码重置为 1。

翻页时则只修改页码，保留原有查询条件。所有查询参数最终都由 `go()` 统一生成，避免多个事件处理函数分别拼接 URL。

## 八、验证与整理

完成后，检查以下场景：
